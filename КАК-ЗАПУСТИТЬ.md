# Avros: бэкенд для загрузки глав

Файл: `avros-worker.js`. Это серверная часть, которой у Avros сейчас нет: приложение ходит через чужие публичные CORS-прокси, они часто не работают, поэтому главы не грузятся.

## 1. Развернуть (бесплатно, 3 минуты)

1. Зайди на **dash.cloudflare.com** → **Workers & Pages** → **Create** → **Create Worker**.
2. Назови, например, `avros-backend` → **Deploy**.
3. Нажми **Edit code**, удали всё и вставь содержимое файла `avros-worker.js` → **Deploy**.
4. Скопируй адрес worker'а: `https://avros-backend.твой-аккаунт.workers.dev`.

## 2. Подключить в приложении

В Avros: **Настройки → «Свой сервер (необязательно)»** → вставь адрес worker'а → **«Сохранить и проверить»**. Должно появиться «Прокси работает».

Проверить в браузере:
- `https://...workers.dev/ping` → `ok`
- `https://...workers.dev/health` → состояние MangaDex и ReManga

## 3. Что умеет

- `/api?url=...` — прокси любого адреса с нормальными заголовками и обходом CORS
- `/img?url=...&ref=...` — картинки с нужным Referer (важно для ReManga)
- `/search?provider=md|rm&q=...` — поиск манхвы
- `/chapters?provider=md|rm&id=...` — список глав
- `/chapter?provider=md|rm&id=...&quality=full` — адреса страниц главы
- `/read?url=...` — вытащить картинки с обычной страницы
- кэш: тексты 5 минут, картинки — сутки

## 4. Важно

Бэкенд означает только загрузку глав. Если в приложении не работает **вход**, это уже Firebase: в `index.html` прописан проект `avros-9ea1e`, нужно создать свой проект Firebase и вставить свой `firebaseConfig`. Также Google-вход не работает, если открыть файл напрямую с телефона — сайт должен быть на ссылке (https), например GitHub Pages.

Если после подключения `/health` показывает, что MangaDex отвечает проверкой «не бот», значит этот источник сейчас закрыт для серверных запросов — тогда используй ReManga или загрузку глав файлами/ZIP.
