# Avros: бэкенд для «читать вместе»

Сайт уже на `https://ras4ek.github.io/Avros/`. Значит для совместного чтения нужно только оживить Firebase: в коде уже есть комнаты, синхронная прокрутка, курсоры, чат, реакции, друзья и корона хоста.

## 1. Создать проект Firebase

1. Зайди в **console.firebase.google.com** → **Добавить проект** → назови, например, `avros-read`.
2. Внутри проекта нажми **«Добавить приложение» → Web (`</>`)** → зарегистрируй.
3. Firebase выдаст `firebaseConfig` — он понадобится на шаге 5.

## 2. Включить вход

**Authentication → Sign-in method** — включи три способа:

- **Google**
- **Почта и пароль**
- **Анонимный** (кнопка «Продолжить без аккаунта»)

## 3. Разрешить твой домен

**Authentication → Настройки → Авторизованные домены** → добавь:

```
ras4ek.github.io
```

Без этого вход будет падать с ошибкой `auth/unauthorized-domain`.

## 4. Создать базу и правила

**Realtime Database → Создать базу** → регион `europe-west1` (или любой) → режим «тестовый» пока не вставишь правила.

Потом **Правила** → удали всё и вставь содержимое файла `database.rules.json` → **Опубликовать**.

Правила дают: каждому — читать чужие профили и комнаты, писать только своё; комнаты и личка доступны вошедшим.

## 5. Вставить конфиг в сайт

Открой `index.html`, найди блок (строки 394–404):

```js
const firebaseConfig = {
  apiKey: "...",
  ...
};
```

Замени его на свой конфиг из шага 1. Сохрани файл и запушь в GitHub — GitHub Pages сам обновит сайт за минуту.

## 6. Проверить «вместе»

1. Открой `https://ras4ek.github.io/Avros/` → войди через Google.
2. Нажми **«Создать комнату»** → скопируй ссылку-приглашение из чата.
3. Открой ту же ссылку в другом браузере или в инкогнито → войди под другим аккаунтом.
4. Должны появиться второй курсор, отметка страницы участника, чат и синхронная прокрутка.

## Итоговая схема

```
GitHub Pages (сайт)
 ├── Firebase  → вход, комнаты, курсоры, чат, друзья  ← «вместе»
 └── Worker    → загрузка глав с MangaDex/ReManga     ← «манхва»
```

Оба файла — `FIREBASE-SETUP.md` и `КАК-ЗАПУСТИТЬ.md` — лежат рядом с `index.html`. Оригинал не переписан.
